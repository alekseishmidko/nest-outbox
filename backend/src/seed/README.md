# Seed Module

## Цель

Модуль `seed` отвечает за генерацию тестовых данных для пользователей, карт, заказов, медиа и Outbox-событий.

## Планируемая структура

- `commands`: команды запуска seed.
- `factories`: генерация fake-data через `@faker-js/faker`.
- `services`: сценарии заполнения БД.

## Основные задачи

- Seed пользователей.
- Seed карт.
- Seed заказов.
- Seed Outbox-событий.
- Reset тестовых данных.

## SQL-фокус

- Bulk insert.
- Транзакционное заполнение.
- Подготовка данных для нагрузочных тестов.
