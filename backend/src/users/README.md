# Users Module

## Цель

Модуль `users` отвечает за пользователей приложения. Эти данные будут использоваться для генерации avatar-контента, создания заказов и SQL-запросов с `JOIN`.

## Планируемая структура

- `controllers`: HTTP endpoints для CRUD пользователей.
- `services`: бизнес-логика пользователей.
- `repositories`: raw SQL-запросы к таблице `users`.
- `dto`: входные DTO с `class-validator` и `class-transformer`.

## Основные задачи

- Создание пользователя.
- Получение списка пользователей.
- Получение пользователя по `id`.
- Обновление пользователя.
- Удаление пользователя.
- Генерация `avatar_seed`.

## SQL-фокус

- `SELECT`.
- `WHERE`.
- `ORDER BY`.
- Уникальный индекс по `email`.
