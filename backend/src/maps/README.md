# Maps Module

## Цель

Модуль `maps` хранит объекты, для которых можно генерировать QR-code. Карты связаны с пользователями через `owner_user_id`.

## Планируемая структура

- `controllers`: HTTP endpoints для CRUD карт.
- `services`: бизнес-логика карт.
- `repositories`: raw SQL-запросы к таблице `maps`.
- `dto`: входные DTO.

## Основные задачи

- Создание карты.
- Получение списка карт.
- Получение карты по `id`.
- Обновление карты.
- Удаление карты.
- Получение карт пользователя.

## SQL-фокус

- `JOIN` с `users`.
- Индекс по `owner_user_id`.
- Географические поля `latitude` и `longitude`.
